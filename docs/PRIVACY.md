# 隐私说明（I1 · 文档模板，上线前需运营/法务最终确认）

> 目的：给 LINE 控制台与商店提交用的「隐私政策 / 利用規約」提供数据清单底稿。
> 正式上线前请把本文改写为可公开访问的独立页面（部署到你的 HTTPS 域名），
> 并把 URL 填入 LINE Developer Console 与商店后台。

## 1. 我们收集的数据（均与账号体系绑定）

| 数据 | 来源 | 用途 | 存储位置 |
|---|---|---|---|
| 平台唯一标识（openid） | 游客设备 UUID / LINE id_token 的 sub | 账号识别、防作弊 | `hd_users.openid` |
| 昵称 / 头像 | 玩家自设 / LINE profile（仅授权后） | 排行榜展示 | `hd_users` |
| 国家 / 区域码 | 玩家自选（区域排行） | 区域排名 | `hd_users` |
| 登录时间 / 次数 / 客户端版本 | 登录行为 | 风控与运营分析 | `hd_users` |
| 对局时长 / 局数 / 通关成绩 | 每次开局与结算 | 时长统计、疲劳管控、排行榜 | `hd_player_daily` / `hd_records` |
| 通关记录时间点 | 结算上报 | 排行榜与防作弊 | `hd_records` |
| 道具与货币余额、变动流水 | 游戏内获得/消耗 | 道具经济、对账审计 | `hd_user_props` / `hd_wallets` / `hd_wallet_logs` |
| 埋点事件（关卡开始/结束、道具使用等） | 客户端行为上报 | 留存/体验分析 | `hd_events` |
| 作弊日志 | 防刷校验触发 | 反作弊审计 | `hd_cheat_logs` |

## 2. 我们不做什么

- 不采集通讯录、相册、精确位置、短信等非必要权限
- 不向第三方出售个人数据；除 LINE（身份登录）与云服务商（数据托管）外不共享
- 埋点不含完整 openid，一律以内部数字 user_id 关联

## 3. 数据保留与删除

- 账号注销：玩家可在游戏内发起（后端 `DELETE /api/user/me`，需二次确认），
  删除后本人**全部**数据（含流水与埋点）即刻清除
- 运营日志（防作弊、审计）如需保留，建议匿名化后限 90 天并标注用途

## 4. 第三方与安全

- LINE：仅用于 LIFF 登录取 id_token（`aud` 校验后丢弃原始凭证）
- 托管：阿里云 OSS / MySQL / Redis 等，均走加密连接
- 防作弊校验需要短暂的时间戳与会话信息（Redis，自动过期）
